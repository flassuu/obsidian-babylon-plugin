# Babylon — Changelog

All notable changes to the **Babylon** plugin for Obsidian are documented on this page.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- **Preset system** — visual note builder (Stage 3.7):
  - JSON preset sidecars per media type that act as the single source of truth for note construction and sync.
  - Visual preset editor modal with drag-to-reorder fields, editable property names, `apiKey` selection, per-field sync toggles, and formatting flags.
  - Formatting engine (value maps, case/capitalization, date formats, number scaling) applied both when writing frontmatter and when comparing during sync.
  - Hybrid note creation: frontmatter generated by the preset, body provided by the `.md` template via preset property aliases.
  - Preset picker at note creation when multiple presets exist and none is marked as default.
  - Preset list in settings with create, duplicate, delete, and set-as-default actions; legacy template/field-map mode kept under a "Legacy" section.
- **Sync v2** — field map + batch review (Stage 3.5):
  - Field-map JSON sidecar that decouples sync from templates and allows user-renamed frontmatter properties.
  - Batch review modal with per-note collapsible sections and per-field checkboxes, plus apply/skip/ignore actions.
  - Per-note ignore list persisted in settings, with a "clear per-note ignores" button.
  - One-way AniList → Obsidian sync with property name resolution (property → key → case-insensitive).
  - Field-map editor modal and debug-level per-field comparison logging.
  - `advancedScores` automatically expanded into individual sub-field sync changes.
- Reworked settings tab: collapsible per-group sections, rounded per-group boxes, enable toggles in group headers that drive the open state, and a redesigned anime section.
- Token help bubble on the AniList token row that shows the step-by-step authorization guide on hover.
- Test-connection button reporting username, total entries, episodes watched, and mean score.
- Surgical frontmatter updates that preserve quoting, arrays, and comments.
- Changelog button in the About box that opens this file.

### Changed

- Settings are now grouped into collapsible sections using the native Obsidian `.setting-group` structure; header text is aligned with the setting rows and group gaps/heights are unified.
- The sync engine uses the active preset when one exists and falls back to the legacy field map otherwise.
- Advanced-score keys are normalized to camelCase to match the local frontmatter convention.
- Russian UI strings use polite formal ("Вы") forms; all descriptions end with a period; em-dashes replaced with regular hyphens.
- All array frontmatter values use the Obsidian List property type.

### Fixed

- Per-note ignore overrides silently blocking field sync — now surfaced with an "ignore" action and a "clear per-note ignores" setting.
- Advanced-score key normalization and Date coercion during surgical frontmatter updates.
- Non-sync frontmatter fields being dropped during sync.
- Settings re-renders moving the scroll position; header clicks no longer fold toggle-driven groups.
- The Discord logo being clipped on the left and right edges in the About box.
- Obsidian 1.13+ rendering only the declarative setting rows and skipping the full settings UI.

## [0.1.0-beta.1] - 2026-07-19

### Added

- AniList provider with search and details via GraphQL, using a dynamic query assembled from the selected fields.
- "Add content" command with a type picker, search modal, and automatic note creation.
- Template system with `{{placeholder}}` syntax, a built-in default anime template, and configurable output folders per media type.
- Settings tab with an About box (author, GitHub/Discord/Discussions/Donate links), General section (language en/ru, template folder), Media Types section, and API key storage.
- i18n system with English and Russian translations.
- Field registry with ~40 AniList fields across six categories (identity, info, ratings, technical, personal, advanced).
- Visual field selector and template generator modal.
- `advancedScores` exposed as individual template fields.
- Title fields split into `title_en`, `title_jp`, `title_ro`, and `title_ru` (the latter extracted from AniList synonyms).
- AniList OAuth flow with token validation and account statistics display.
- "Add from AniList" import of the user's personal list.
- Overwrite-confirm modals for templates and notes, and auto-open of created notes.
- Type-aware YAML generation (quoted strings, bare numbers, YAML lists for arrays, ISO dates).

### Changed

- Settings UI restructured around the About box and per-media-type layout.
- Media fields split into identity and info categories; complex fields (trailer, rankings, etc.) marked advanced and hidden from the field selector.
- Note filename format `{Title} - {sourceId}.md`.

### Fixed

- 400 errors on detail fetch by simplifying the AniList GraphQL query.
- Template files not being applied — now read through the vault adapter.
- Template path normalization for absolute and vault-relative paths.
- A single invalid GraphQL field no longer failing the whole query (retry mechanism).
- Arrays of objects flattened correctly; empty values kept as placeholders.
- Date values padded to two digits for the Obsidian Date type.
